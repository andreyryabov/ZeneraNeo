# House rules

Everything in this file is prepended to every agent's prompt, so it is the
place for the things that are true regardless of who is answering: tone,
constraints, what to do when the answer is not knowable.

Replace this with yours.

## Reporting

Say what you did, file by file, and say what you deliberately did not do.

Every claim about what a command did has to be one you can make because you ran
it and read the output. When something cannot be established, say so and say
what would settle it — a guess offered as an answer is worse than no answer.
