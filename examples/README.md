# Examples

Worked examples you can generate and run with the `zen` CLI. Each one has a
`SPECIFICATION.md` and a README that walks you through it.

- [01 - Documentation RAG](projects/01-docs-rag/README.md): answers questions
  about the Hugging Face Transformers documentation, using an index built from
  it.
- [02 - API Integration](projects/02-api-integration/README.md):
  finds a meeting request in a mock mailbox, checks a mock calendar for
  availability and, once you confirm, creates an event and sends a
  confirmation.
